# Movie frontend

Use Node.js 26.13+ (26.x), then `npm ci` and `npm run serve`.
The app uses Vue 3, Vue Router 5, Vite 8, ESLint 10 and Bootstrap 5.
Run `npm run lint`, `npm run build` and `npm audit` before submitting changes.
Set `API_PROXY_TARGET` for the development API proxy or `VITE_API_URL` for a
separate API origin in production builds. See the [root README](../README.md)
for full setup and Docker instructions.
